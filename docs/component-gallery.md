# 组件与样式展示页

启动 `npm run dev`（或只启动前端 `npm run dev:web`），访问 <http://localhost:5173/dev/components>。不要求管理员登录；示例使用本地虚构数据，不调用业务写入接口。应用外层仍会读取会话和站点配置。

## 使用

- 左侧搜索支持名称、描述和源文件路径；点击分类标题可连续查看整组。
- 顶部沿用全站主题选择。主题设置会保存为站点偏好。
- 自适应、768px 平板、390px 手机使用 iframe 的真实视口；可用空间不足时收窄至容器宽度。独立预览可直接使用浏览器响应式工具检查其他尺寸。
- 状态列表只提供所选示例支持的状态。整组预览中不支持该状态的示例会标注并展示默认状态。
- 边界内容用于检查已实现该选项的示例，例如长书名、多行简介和大数字；“重置”重新加载预览，清除示例内部交互状态。
- “查看真实源码”按需加载关联源文件；“复制链接”保留示例、状态、边界内容与选中的源码文件。预览宽度通过页面上的宽度按钮选择。

## 覆盖范围

初始版本有 33 组交互示例，覆盖现有 `components/ui` 全部组件文件，以及小说卡片、封面状态、后台状态、分页、搜索选择、时间选择、异步状态、访问提示、后台弹窗、行内操作、首页筛选、原生按钮、后台页头、阅读设置与阅读纸面。

源文件索引自动枚举 `components/**/*.tsx`、`pages/**/*.tsx` 与 `styles/**/*.css`，排除测试和展示页自身。初始收录 262 个文件，其中 64 个文件关联了示例。“已关联”表示至少有一组示例引用该文件，不表示每个属性、分支和业务流程均已展示；“待补交互示例”的文件可以查看源码，但还没有交互预览。

复杂业务弹窗、账户流程、图表和部分阅读器面板仍可通过索引定位，后续按需补充隔离的场景示例。不得为了补覆盖而直接挂载会请求真实数据或执行写入的完整业务页面。

阅读节拍指令示例复用阅读器的原位弹窗与紧凑控制条，并登记 `EdgeControls` 的生产源码。计时入口仅在真实成人内容权限确认后显示，示例不模拟放行；记录使用独立的 `gallery:reader-tempo` 本机空间。

## 维护

示例组件位于 `web/src/pages/dev/gallery-examples.tsx`；在 `gallery-catalog.ts` 注册名称、分类、来源、使用场景和支持状态。分类与状态类型在 `gallery-types.ts`，目录、iframe 与源码查看器在 `ComponentGallery.tsx`。

新增示例应直接导入已有组件或复用页面真实结构与类名。保留所需的样式上下文，例如书库卡片的 `.home-page`、阅读设置的 `.reader-app`。`gallery.css` 只负责展示页布局、间距和预览尺寸，不复制或覆盖被展示组件的外观。样例状态保存在示例组件内部，不写真实书架、阅读设置或业务数据。

入口由 `import.meta.env.DEV` 包围的动态导入注册；生产构建会排除展示页模块、示例数据与源码查看器，访问该路径沿用现有未知路由处理。访问统计跳过开发环境下的 `/dev/` 路径。

## 验证

此次实现已执行前端类型检查、修改文件 ESLint、Prettier、生产构建及浏览器验证。浏览器验证包含 1280px 亮色和 390px 暗色下的四组示例、禁用/加载/错误/空内容状态、长内容、搜索、源码索引、真实 iframe 宽度、对话框焦点返回、下拉搜索、时间选择、提示/确认、抽屉与分页。未发现页面运行错误、页面横向溢出或业务写入请求；长表格保留自身的横向滚动。
