# 来源想法

阅读器将书源的章节内段评接入既有「想法」面板。当前私有适配器实现番茄小说，公开构建只提供通用接口，不含私有端点、签名或凭据。

## 阅读行为

- 段落入口数量为本站想法加上已匹配的来源统计；来源数量取原平台统计与本段已保存主评论数量的较大值，不承诺与翻页期间变化的总数完全一致。
- 面板支持全部、本站和来源筛选，本站内容在前。来源段评、回复、昵称、图片与赞数只读；发表、删除及图片生成仍走本站原有功能。
- iOS 面板隐藏原文引用，以原生导航、来源分段控件和留白评论列表呈现，输入与「发布到本站」常规字号同排，沿用现有玻璃材质。辅助功能字号使用可换行布局和原生来源菜单。
- 「全部」中不为零条本站想法展示独立空态；只有本站和来源均确认没有内容时显示整体空态。切换来源保留草稿、已加载的来源页和回复展开状态；来源筛选下发布本站想法成功后回到全部。
- 来源失败可独立重试，本站草稿和操作不受影响。切换章节、段落或账号后，旧响应不能填入新面板。
- iOS 离线阅读不请求来源段评；本次入库发生在服务器，未增加手机离线评论库。没有适配器能力且没有已保存快照时不显示来源筛选；适配器暂不可用时仍可读取原来源下已保存的评论。

## 接口与匹配

`GET /api/source-thoughts` 使用现有阅读身份。必填 `chapterId`；`action` 可为 `counts`（默认）、`comments`、`replies`。后两者需当前 `paragraphIndex` 和 `paragraphHash`，回复另需字符串 `commentId`，分页使用 API 返回的本地稳定 `cursor`（`s:<行序号>`），不要自行构造来源游标；旧数字游标按本地偏移兼容。可选 `refresh=1` 请求检查更新，来源请求的游标只保存在服务器。返回的可选 `sync` 含状态、已保存数量、更新时间及当前列表是否完整，旧客户端忽略这些字段仍能读取评论。

服务端先验证作品可见范围及受限内容权限，再从已保存的书籍和章节来源解析适配器。客户端不能传入任意上游地址。响应使用 `private, no-store`，错误不透传中转地址或凭据。

核心将当前本地段落与来源正文匹配：整章内容和顺序一致时保留位置；编辑后只接受唯一文本匹配，重复句需相邻上下文同时吻合。同一来源段落不能分配给多个本地段落，无法消歧时不挂载。客户端再次验证当前正文哈希，适配器验证每条段评的来源书籍、章节、原始段号及引用原文，回复验证书籍、章节和父评论。

通用数据模型不包含本站用户 ID 或权限。来源 ID 全程使用字符串；图片仅允许适配器列出的 HTTPS CDN。来源评论单独写入持久化表，不导入本站想法表。中转与适配器的两分钟短时缓存继续保留；服务器快照不按短时缓存期限删除，失败不会伪装成成功的空列表。

## 入库与后台同步

- 迁移 `105_source_thought_snapshots.sql` 增加章节快照、段评／回复分页进度、评论内容和待登记章节四类记录。正文保存时只登记任务，不等待来源网络请求；数据库触发器覆盖文件融合、本机抓取和章节接口等其他保存路径。章节删除级联清理相应快照与进度。
- API 每两秒尝试处理待办，进程内只运行一轮；先登记至多 20 章，再为一个章节读取一页。正在运行的正文抓取优先，后台评论暂缓；用户打开尚未保存的页面时仍可按需读取。现有书籍在后续抓取／追更结束时补登记旧章节，也可在阅读某章时补登记，不在部署时自动重抓整个书库。
- 先获取章节来源段落和数量，再读取有评论的段落，主评论优先于回复。每页内容、去重更新和游标原子提交；章节租约为两分钟，进程退出后由下一轮接管过期租约。失败保留旧内容和游标，重试从一分钟逐步退避至一小时；重复／循环游标及不完整协议页拒绝提交。
- 已完成快照在阅读或书籍更新时超过五分钟可排入检查；手动更新保留两分钟的最短刷新间隔。同步暂停时手动更新遵守退避；达到刷新间隔后可重新核对来源段落，已有内容继续保留。后台不会无限轮询所有已完成书籍。
- 使用来源身份、章节、原始段号和文本哈希隔离数据；换源会清理不再属于当前来源的快照，迟到请求不能写回旧任务。原文修改后继续使用已有唯一匹配规则，不能定位的评论不挂到其他段落。返回数据前仍校验作品可见范围、内容分级及父评论归属。
- Web 与 iOS 沿用原生／现有想法布局，用次级文字显示等待、同步、暂缓、来源不可用和完成状态，以及已保存数量和更新时间；未同步完的空页不显示“没有评论”。更新按钮重新读取服务器快照并请求检查更新；本轮没有增加持续轮询界面的计时器。
- 默认保存正文、作者展示信息、赞数、回复关系和图片 URL，不复制来源头像或配图文件。没有提供明确删除信息时，来源某页未出现的旧评论继续保留；通用适配器可返回明确 `deletedIds` 以隐藏对应内容及回复，当前番茄接口不保证提供此类删除标记，不能宣称已完整追踪原平台删评。

## 发布依赖与限制

基础来源读取依赖私有 `fanqie-relay 0.4.0` 和对应适配器。持久化功能须先备份并应用 `105_source_thought_snapshots.sql`，再发布 API，最后发布 Web／iOS；API 启动也会自动执行未应用迁移。本轮沿用原有中转和适配器，无需升级它们。中转继续使用既有配置、设备凭据、请求间隔及风控冷却；来源仍可能因凭据或上游变化暂时不可用。旧客户端可读取已保存评论，但同步状态和更新按钮需配套新版客户端。

2026-11-28 的只读实测已确认一章 80 个正文段落与本地内容完全对应，27 个段落有评论，并验证了段评分页和真实回复结构。这是特定样本的协议验证，不代表全部书籍均能获取。随后同日 14:33 已完成独立中转升级和生产网站的统计、段评、回复读取验收；构建、部署及尚未完成的视觉验收见 [发布记录](releasing.md)。
