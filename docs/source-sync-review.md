# 融合章节名与序号核对

## 核对待办与同步结果

核对区默认显示「有差异」，可切换全部目录，或按未匹配、标题待同步、可修复序号、修复受阻分别筛选。序号已一致的章节不因同名而被列为待修复；受阻汇总只包含实际目标占位导致的移动失败，未匹配和证据不足只作独立核对事项。偏移报告省略零偏移区段，分别统计可修复与受阻数量；编排差异只用于解释目录关系，不再排除排序同步；唯一且高置信度的对应关系可勾选按源站排序，未勾选保持原样。

人工映射编辑展示同名源站候选，可选择候选查看邻章，位置相差较大时提示结合邻章与本地正文核实；候选不会自动保存，拆分组占用仍不可选择。勾选映射后显示所选映射对应的人工标题确认、可修复序号及无需更新数量；自动标题更新不受映射勾选影响，总更新数量以底部为准。若所选章节的目标序号需要其他章节同时让位，显示关联映射数量并提供补选入口；关联选择不完整时禁止应用，服务端仍独立校验占位与全部目录快照。

章节名同步没有变化时展示完成状态，仍存在未匹配本地章时保留核对引导，不显示空比较表头。更新类型由服务端返回，分别解释导入编号清理、推广水印清理、章节标记同步、标点空白调整和拆分标题补全；旧响应只显示通用说明。自动更新禁止向干净标题新增编号或写入推广尾巴，实质改名保持原有人工确认流程。应用旧预览时再次检查方向护栏，发现旧版自动建议不符合新规则则要求重新生成预览。

撤回完成后等待当前作品的标题、作者、章节数和章节列表刷新，再结束忙碌状态；重新打开融合时使用恢复后的作品信息。数据撤回成功但刷新失败时明确区分两种结果，禁止重复撤回，并提示刷新页面。融合及历史弹窗的关闭按钮位于标题区上层，避免视觉可见却被标题背景截获点击。

读取原作者源站后，先按两侧唯一的完整标题定位章节，再在已确认标题的边界内对剩余章节进行顺序、编号匹配。完整标题可以忽略导入编号、空白及常见标点；只出现在加更标记或标题正文里的数字不作为章节号。重复标题不能作为唯一定位依据。拆分标记连续时仍需核对基础标题或同一章节编号，不能把不同章节合成一组。

## 序号修复

预览发现本地重复序号时显示提醒；本地章节能按唯一完整标题一对一定位到源站，且对应源站序号有效、互不重复并且目标位置可用时，在「核对与调整映射」对应行展示原序号、目标序号及勾选后的修复状态，默认不勾选；不再单独展示序号修复开关和列表。没有标题变化时也可以单独选择序号修复，并在应用前确认数量。源站未导入章节形成的序号空缺会保留，不会压缩成连续编号。

未匹配本地章、重复标题、证据不足或拆分章节按项显示不能修复的原因，其余满足条件的章节仍可修复序号，也可使用原有标题确认与元数据同步。服务端重新计算修复方案，不接受客户端传入目标序号，不允许通过直接请求绕过这些限制。

应用序号修复前，在事务内核对全部本地章节的 ID、标题与序号。预览后新增、删除、改名或调整过任何章节时，要求重新读取源站。重复应用同一预览被拒绝；相同操作键的接口重试回放已完成结果，改变修复选项需要新的操作键。

修复只更新现有章节的排序字段，不删除、重建章节或修改正文、书签与阅读进度记录。没有选择序号修复项时保持原序号。更新 API 和 Web 后应重新生成预览，旧预览不会自动补充序号修复展示。

## 人工映射与匹配依据

「核对与调整映射」显示全部本地章的当前对应关系、匹配依据与置信度，支持搜索和分页。依据区分完整标题一致、章节编号一致、标题部分重合、顺序推断及人工指定；拆分关系另行标注。调整时显示两侧前后相邻章节，可选择源站章或解除匹配；选择被普通章节占用的源站章时，明确展示双方交换的对应关系，并将双方加入暂存调整。拆分组占用的源站章仍不可选择。拆分组暂不提供单章重映射。

「有差异」集中显示序号不同、标题不同及未匹配的本地章节，可与搜索一起使用。完整标题一致仍可能存在序号差异；仅有标点、空白或全半角差别不作为明显标题差异。点击「调整映射」后，编辑区在当前章节下方展开，自动滚动并聚焦编辑标题，避免长列表中误以为点击无响应。调整对应关系会重新生成预览；序号修复统一在本列表中勾选，核对后通过底部按钮应用。

映射调整先暂存，可连续处理多章再统一保存。保存会基于原始目录快照重建预览并递增版本；只保留本地标题、序号、对应关系及实际更新均未变化的人工确认与勾选，受调整影响的项需重新选择。暂存调整尚未保存时，底部应用及重新匹配操作禁用。人工映射产生的标题变化必须重新勾选确认，不会自动覆盖。可以恢复整次预览的自动匹配。服务端拒绝重复占用、无效目标、拆分组单章修改、陈旧版本和变化后的本地目录。应用请求携带当前版本，兼容初始版本 0 的旧调用；修改过映射的预览不能再使用旧版本提交。

## 融合历史与安全撤回

章节管理工具栏的「融合历史」按当前作品分页展示已应用记录，可按需读取实际变化详情。历史数量来自应用事务内记录的实际标题、序号及小说信息变化，不包括未确认的标题建议。未记录实际快照的旧历史只读展示，不推断恢复值。

撤回逐章比较当前标题和序号与当时应用结果，已再次编辑或删除的章节保留并列出冲突，不重建章节、不修改正文。恢复序号前检查后续章节的占用，防止制造新的重复序号；应用前已存在的重复序号可按原快照恢复。小说信息作为一组核对元数据与内容分级修订；已有编辑或审核则整组保留。恢复分级通过现有治理接口生成新修订，不能倒写历史修订号。

撤回结果持久化，区分已撤回与部分撤回；重试回放同一结果，历史里可重新展开冲突。操作期间禁止关闭弹窗。迁移 `056_source_sync_review.sql` 增加预览版本、人工映射、实际变化、历史摘要和撤回结果字段，需与 API、Web 一起更新。

后续还可以在确认映射后复用来源地址，减少源站改名或本地重复标题造成的二次匹配歧义。

## 映射批量选择与同步默认值

映射核对支持逐项勾选、全选当前筛选结果及清空选择，全选包含所有页。
未匹配、证据不足或拆分章节不再阻塞整本书的序号修复；逐章判断修复资格，排除目标位置被无法修复章节占用的项（包含连续依赖），在映射列表说明跳过原因。勾选直接把对应的待人工核对标题及可修复序号加入本次同步，底部显示
实际标题、序号与小说信息更新数量，点击应用按钮后仍需确认。只有序号
差异、没有标题变化时，也可以通过全选映射执行同步。自动更新标题继续
沿用已有规则；未匹配或没有变化的映射不会产生更新。

序号修复按所选章节提交，未选章节保持原序号；若目标序号被未选章节
占用，事务拒绝应用，并提示一并勾选相关映射。序号修复统一使用映射列表的逐项选择和全选入口。旧客户端未传所选序号 ID 时保留全量修复行为。

同步小说信息默认不勾选字段，每次打开融合弹窗重置为空。用户可以
手动勾选或使用全选可用字段；映射全选不会自动勾选小说信息。

## 同步封面与缓存一致性

勾选封面且 URL 实际变化时，在融合事务内把现有图片保存到封面历史，再清除旧图片缓存；未勾选、仅补缺但已有 URL、URL 不变时不替换现有图片。首次读取下载新 URL 对应的图片，小说更新时间严格递增，供前端封面请求更新缓存版本。

读取封面时，对历史遗留的「源站 URL 已改、缓存来源仍旧」记录自动重新下载；上传、AI 及未知来源的本地封面不参与这一判断。新源图下载失败时移除不匹配的旧源图，返回不长期缓存的占位图，下一次读取仍可重试。下载在事务外完成，写入前锁定小说并检查 URL 和当前图片版本，避免慢请求覆盖之后的同步或上传。

撤回融合检查当前封面来源与元数据，恢复原封面历史快照及 URL；后续手动替换的封面、已清理的原封面历史显示冲突并保留当前小说信息。修复前的融合历史没有图片快照时，只能恢复 URL 并让源站图片重新缓存，不推断或覆盖上传、AI 封面。

Web 封面请求标记从 `cover=3` 更新为 `cover=4`，使已经缓存旧响应的浏览器重新请求；后续同步继续使用小说更新时间刷新。修复不修改线上数据库，部署后历史源图缓存的不一致会在读取时修复，不需要批量清空所有封面。

## 在融合弹窗内连续核对与清理杂章

核对映射的每行可预览本地正文，并单独勾选“杂章待删除”。删除选择与
标题、序号同步选择分开；有待删除项时，先删除或清空删除选择再应用
同步。批量删除前列出全部所选章节并明确确认永久删除正文，使用既有
章节删除接口更新小说章节数；融合历史不能恢复此次删除。

删除后、手动更新本地目录后，以及选择“应用后继续核对”时，复用当前
预览已读取的源站目录和小说信息，为最新本地目录创建新的预览，不重复
访问源站。保留仍存在且可独立映射的人工对应关系，删除章节的覆盖会
移除；拆分关系发生变化时不沿用单章覆盖。原有人工确认只在全部相关
信息不变时保留；应用后继续核对清空已执行选择和小说信息字段选择。

重新匹配会检查原预览版本，只支持未应用或已应用记录，不支持已撤回
记录；新预览应用时仍按最新本地快照检查并发变化。已删除或已应用，
但重新匹配失败时，旧预览禁用，允许重试重新匹配，不重复执行删除或
应用。源站自身目录发生变化时仍需重新读取源站，复用目录只更新本地
快照。保存映射、删除后重新匹配以及继续核对保留当前筛选、分页和
核对区展开状态；小说管理入口会同步刷新列表。
