## 结论与边界

慢主要与实际输出规模、推理开销、增量档案不断增长有关。非流式会让用户直到整次完成才看到结果；切换流式能改善等待反馈，不能承诺降低模型生成总耗时。相同输入不代表这些请求每一条都由自动重试触发，也可能包含手动继续；本次没有据此断言具体触发次数。

DeepSeek 官方文档说明思考模式可通过 `thinking` 与 `reasoning_effort` 控制；实际网关是否按相同语义转发，仍需在部署后以真实请求验证：

- [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)
- [Create Chat Completion](https://api-docs.deepseek.com/api/create-chat-completion/)

本轮新增：

1. 在 AI 参数的「AI 创作」中，分别配置正文/大纲与关系/情节档案的思考模式、实时预览。默认跟随供应商且关闭预览，保持旧行为；显式思考参数仅允许 DeepSeek 命名的兼容模型。模型名称相符并不保证网关支持这些参数。
2. 启用实时预览后，上游采用 SSE，前端通过现有任务轮询显示进度。思考阶段只显示字符数量，不存储或展示思考原文。正文预览最多保留最近 4,000 字符，明确标记尚未完成、尚未保存。
3. 上游输出思考或正文后不再自动重发失败请求；缺少完成标记的断流不会成为正式产物。任务取消后不能恢复为活跃任务，部分内容不能进入草稿或正式档案。
4. 正文生成参数记录耗时、首段正文时间、推理 Token、实际是否流式等诊断；档案最近提取记录首段正文时间、思考模式和实际流式状态。供应商回退 JSON 时记录实际非流式。
5. 档案提示词要求同一人物、关系和线索合并重复描述，压缩逐章复述，保留事实、变化原因、关系边界与章节来源。不硬裁历史正文，不自动缩减 Token 预算，不自动重建旧档案。

验证使用隔离测试数据库与浏览器模拟接口，没有执行付费线上 A/B 测试。不能据此保证关闭或降低思考后的文学质量、档案完整性或具体提速比例。建议部署后先在一小批章节上比较低强度与供应商默认模式，再决定是否调整长期配置。
