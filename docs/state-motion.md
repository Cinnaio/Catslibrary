# Web 状态切换与动效

覆盖阅读空间与管理工作区的页面／分区切换、折叠、浮层、操作条及列表反馈。动效不延后网络请求、清空旧结果或重新挂载整个表单；正文、阅读进度及后台轮询不增加装饰动画。

## 首页与认证页已有行为

首页手机筛选、更多分类标签及登录／注册模式继续沿用以下原位过渡。

- 复用 `--ease-out`；共享 `--motion-state-enter: 180ms`、`--motion-state-exit: 140ms`、`--motion-state-reduced: 100ms` 与 `--motion-state-offset: 4px`。
- 首页使用 CSS 离散 display 过渡保留退出画面，只插值 opacity/transform，不逐帧改变高度。不支持该 CSS 能力的浏览器即时展开/隐藏，不影响操作。关闭区域立即 `aria-hidden` 与 `inert`，必要时将焦点还给触发按钮；已选筛选条件不清除，宽度变化保持桌面筛选可见。
- 键盘／辅助技术触发（click.detail=0）即时响应。指针展开内容从 opacity 0.6 与4px偏移进入，收起反向退出；减少动态效果时只用100ms淡入/淡出，进入起点opacity 0.9、不位移。
- 登录模式使用原生 Web Animations API，保留输入 DOM、值、自动填充与焦点，最多同时过渡标题、字段区和动作区；模式立即更新，初次访问不入场。快速切换先采样当前动画画面，再取消并续接；离开页面或开启减少动态效果后清理动画。没有 API 时即时切换。
- 默认样式始终可见，不增加动画依赖、等待遮罩、交错延迟、持续循环或动画期间禁用操作。错误、注册策略、提交与来源页回跳沿用原行为。

验收需覆盖桌面/手机、快速开关、键盘即时响应、减少动态效果、隐藏控件不可聚焦、条件保留、输入节点和值保留及提交回归。浏览器测试使用模拟接口，不代表真实登录／注册写入。

## 统一节奏

基础来源为 `web/src/styles/tokens.css`，后台令牌只做映射。

| 场景 | 进入 | 退出 | 表现 |
| --- | --- | --- | --- |
| 分区／展开收起 | 180ms | 140ms | 分区淡入；折叠高度、边距和透明度衔接 |
| 弹窗／遮罩 | 180ms | 140ms | 淡入淡出，弹窗最多缩放至 0.98 |
| 菜单／选择器／提示 | 160ms | 120ms | 轻量淡入与缩放，保留方向和锚点 |
| 侧边／底部抽屉 | 240ms | 180ms | 沿抽屉方向进入与退出 |
| 按钮／开关反馈 | 160ms | 160ms | 原有颜色、按压与开关位移 |

顶栏收拢沿用 280ms；后台数据行覆盖实际全部条目，将错峰延迟限制在 240ms 内。列表入场位移统一为 4px，主动检索结束时平滑恢复透明度，移除表体模糊。

## 共享实现与边界

- `components/ui/motion.tsx` 的 `MotionView` 用于分区呈现。`asChild` 保留布局元素，`motionKey` 仅传视图标识，不传请求计数、输入文字或轮询时间。只改变透明度，避免 transform 改变内部固定操作条的定位参照；共享 Tabs 活跃面板使用同一节奏，隐藏面板立即移出布局。
- `MotionPresence` 与 `hooks/useMotionPresence.ts` 管理退出周期：关闭立即设置 `inert`、`aria-hidden`，必要时归还入口焦点，退出后隐藏或卸载。`keepMounted` 保留输入节点；快速反向操作从当前画面续接，旧回调不能关闭已重开的区域。离页、标签隐藏或减少动态偏好变化清理动画，无 Web Animations API 时即时切换。
- 共享 `Collapsible` 保留 Radix 受控／非受控状态和 Trigger 语义，复用退出周期。侧栏子导航、添加 Passkey、阅读数据预览、风控表单、AI 图表、抓取连接／配置／日志与桌面阅读工具接入该能力；侧栏不同实例使用独立控制 ID。
- `MotionDetails` 保留原生 `details`／`summary`、`open` 和事件。支持 `::details-content` 与离散过渡时淡入淡出，支持 `interpolate-size` 时额外平滑收展空间；不支持时保留原生即时行为和浏览器查找能力。
- 共享弹窗、确认框、菜单、下拉选择、提示与抽屉通过 `overlay-motion.module.css` 统一节奏，继续由 Radix 管理焦点和 Escape。移动工作区导航采用同一组令牌。
- `AdminFloatingDock` 接收 `open`，由自身保留退出画面与占位，调用方不提前卸载。批量条取消独立的固定退出计时器；配置、参数、邮件、安全策略和备份保存条共用生命周期，退出期间不可操作。
- `hooks/useListMotion.ts` 仅由已成功的用户操作触发。书架移除收藏／阅读记录先淡出，再按保留节点的位置补位，不复制 DOM。动作结束再次检查账户／操作上下文；离页及偏好变化取消视觉等待。焦点移交相邻书目或当前分区入口。

新增动效在减少动态效果下即时呈现；认证页保留既有 100ms 纯透明度方案。后台同步使用原静默数据流，保留内容、滚动位置和按钮状态；页面／分区动效及新增列表补位不以普通数据更新为重放条件。请求、权限、草稿与错误处理仍由原业务模块负责。

## 展厅与验证

开发组件展厅 `/dev/components?item=motion` 提供分区、折叠、原生说明、书目补位与保存条示例，直接使用生产组件；`dialog`、`sheet`、`overlays`、`disclosure` 示例覆盖共享浮层。

定向检查覆盖草稿和输入节点、快速反向开关、旧回调隔离、退出期焦点、减少动态效果、无动画 API 降级、卸载清理、静默更新、书架失败／账户隔离与阅读面板互斥。浏览器使用隔离 API 和组件示例，不执行真实账号操作；构建和交付状态见 `docs/releasing.md`。
