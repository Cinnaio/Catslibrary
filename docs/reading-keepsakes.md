# 合上书以后

一本书读到当前目录末尾，或者只是想记下此刻的感受时，可以为自己留一张藏书票。它是私人留念，不会改变阅读进度、自动标记完读或发布评论，也不调用 AI。

## 使用方式

- Web：书籍详情的「合上书以后」，或当前最后一章正文后的「合上书以后 · 留一页余温」。
- iOS：书籍详情工具栏的书本按钮、在线阅读器的更多菜单，以及滚动阅读的目录末尾。离线阅读不显示在线留念入口。
- 写下「这本书留给我的是……」，或选一则自己的想法，即可保存。最多选择三则，原来划选的句子与想法一起留下；寄语限 280 个 UTF-16 单元，两端按同一规则计数。
- 候选来自这本书中本人当前可见的最近 50 则想法，可在二刷时再次选择旧想法。不把书签备注当作原文，不读取其他读者的想法。
- 已有藏书票时先打开最近的一张，下面可以翻看历史，每页十张。「再留一页」创建新的草稿，不覆盖旧页。
- Web 可下载 TXT，iOS 可用系统分享导出文字。当前版本不导出藏书票图片。分享由用户主动发起，保存本身不会公开。
- 删除需要确认，仅删除指定藏书票；原来的想法和阅读记录保持不变。未保存的编辑留在当前面板，关闭后不会写入云端。

## 日期与快照

日期统一按北京时间展示。开始日期只取服务端实际阅读统计记录中，这本书在上一张仍保留的藏书票之后的最早阅读事件；没有记录时不显示起点。第一次留页也不从加入书架或注册日期推测阅读开始时间。保存时间由服务端生成，不宣称是全书读完日期。

保存时服务端重新读取本人的所选想法及章节标题，固定书名、作者、原句、想法和寄语。以后修改或删除原想法不会改写已存文字。封面保存来源地址用于元数据，展示沿用当前受控封面接口；没有存储封面图片副本，因此封面可能随作品更换。封面加载失败时使用书本占位。

## 接口与一致性

所有接口以 `/api/reading-keepsakes/:novelId` 为前缀，需要登录，响应采用 `private, no-store`，按当前作品可见性及内容模式校验；即使是已保存快照或相同请求的重试，也不能绕过访问限制。所有查询与写入绑定当前账号，不接受客户端传入所有者。

- `GET /context`：书目信息、最新藏书票 ID、阅读记录起点、候选想法与截断提示。
- `GET /`：返回最多十张藏书票及 `nextCursor`，通过 `before` 继续查看。
- `POST /`：接收 `id`、显式可空的 `previousId`、`momentIds` 与 `closing`。服务端校验范围与所有权，用账号行锁串行化保存，保存标识及请求摘要实现幂等。旧草稿遇到其他设备的新页返回 409，不静默覆盖。
- `DELETE /:id`：仅清除本人的该张藏书票。立即抹掉快照文字，保留保存标识及摘要作为删除标记；迟到的相同保存请求返回 410，避免恢复已删数据。删除账号或作品会级联移除该表对应行。

保存响应不确定时，两端保留相同请求标识及完整载荷，锁定编辑并提供同次重试。也可以关闭后重新打开，先确认是否已经保存。账号、内容模式或面板生命周期变化会丢弃旧响应；失去作品权限后会清空已加载内容。留念面板打开期间，阅读统计和自动滚动暂停。
