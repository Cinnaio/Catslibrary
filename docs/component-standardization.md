# Web 组件规范化

## Goal 与完成条件

范围是整个 Web，包括前台、后台、阅读器、所有浮层与开发组件展厅。基线为 `9655e260`，2026-11-04 盘点得到 94 个组件文件、236 个非测试生产源码模块。盘点数字不代表全部需要重写。

2026-11-05 按用户补充要求收口：只处理组件归属、共享实现、样式所有权及必要验证；不追加业务功能、页面改版、性能专项或全量业务验收。

- 基础控件放在 `components/ui`，通用组合放在 `components/shared`；工作区、后台、阅读器与业务组件保留明确场景边界。
- 公共层不得反向依赖后台、页面、会话或业务接口。需要业务数据、权限、导航目标或请求时，由使用方提供。
- 共享意味着一份生产实现与一个样式所有者；页面仅负责布局与有业务意义的组合。保留有依据的差异，禁止用越来越多的布尔参数构造万能组件。
- 所有迁移必须更新生产使用方、测试与展厅；不以只搬目录、兼容转发文件或只有示例的新组件作为完成。
- 保持已确认的“小控件、大留白”。同尺寸语义、主题、焦点、disabled/loading/error 与移动安全区属于组件契约。
- 不删除功能、不更换框架或控件库，不改 API、权限、账户隔离、持久化格式、URL、任务、草稿与批量范围。阅读器的虚拟化与特殊阅读控制保留。
- 不执行真实业务写入、数据库迁移、外部发布、推送、部署或历史改写；未经新的用户指令不提交。
- 不主动截图或跑冗长全量套件。必要契约变化做定向检查，类型、生产构建、样式转换与业务验收分别记录。
- 只有下述清单和组件分类有最终依据、全部迁移使用方闭合且检查完成，才结束 goal。局部完成、耗时或预算不能代替完成。

## 归属与迁移结果

`ui` 中的 Radix 原语已有统一实现，应收口外观所有权而非替换交互库。`CustomSelect`、`CustomTimePicker`、`AdminFormField` 和面板异步呈现不包含业务请求，可迁到公共组合层。`AdminWorkspace` 是多个独立组件的集合，不应作为默认业务依赖入口。

`AdminPage`、表格列定义、批量选择与行操作属于后台场景共享。`ScrapeField` 和 `AiPanelEmptyState` 已复用底层，且表达抓取字段和供应商未配置等业务语义，保留薄包装。`PageState` 会控制整页外壳，不能与普通空态简单合并。阅读目录虚拟列表、章节图片、阅读设置与移动阅读工具栏保持阅读场景归属。主题、账户、内容策略、会话恢复与阅读数据组件包含业务状态，不能下沉到无业务的公共层。

| 原实现／职责 | 最终归属与处理 |
| --- | --- |
| `CustomSelect`、`CustomTimePicker` | `shared/SearchSelect`、`shared/TimeField`，保留受控值、搜索与折叠；业务时间预设由调用方传入 |
| `AdminFormField`、`AdminEmptyState`、`AsyncStates` | 共享字段、面板空态与异步呈现，自带样式；字段统一标签、说明与错误关联 |
| `AdminDialog`、后台分页 | `shared/DialogFrame`／`DialogBody`、`shared/Pagination`；前台分页复用同一实现，查询和页码仍由页面控制 |
| `AdminWorkspace` 已消费职责 | `admin/AdminToolbar`、`AdminDataPanel` 与共享 `SearchField`、`PanelHeading`、`CellText`；时间样式归 `AdminModelTime` |
| `AdminWorkspace` 未消费导出、`AiSettingsCard` | 移除无生产使用方的上下文／指标／队列呈现及设置卡片，不新增无人使用的抽象 |
| `FloatingPageTools` | 迁至 `shared`，详情页与阅读器共用；减少动态与滚动策略归 `lib/motion` |
| `ui/UserAvatar` | 纯呈现归 `ui/Avatar`；资源地址解析归 `identity/UserAvatar`，公共层不再依赖 API |
| 原生通用按钮、加载图形、书库筛选片 | 消费已有 `Button` 或共享 `Spinner`、`FilterChip`，保留链接、选中状态与动作回调 |
| 原语皮肤与表面 | Card、Panel、Input、Switch、Checkbox、Tabs、Toggle 由原语维护；后台尺寸和 portal 继承设计外观 context |

原路径已移除，生产使用方、测试引用与展厅直接使用新实现。页面内业务子组件按所属工作流保留，未强行拆成公共组件。当前清单覆盖 103 个组件文件、247 个生产源码模块（加上 4 个开发展厅模块，依赖检查共 251 个源码模块）；新增数量来自职责拆分，不代表业务功能增加。

`global.css` 只导入设计令牌、基础样式与框架桥接；原通用聚合样式中仍有效的账户、书库、阅读器和管理布局规则由对应入口加载。组件皮肤不再依赖另一条路由偶然加载。共享层不使用 `--admin-*`，管理场景以角色令牌赋值。既有 scene CSS 继续服务表格、阅读及业务布局，不为追求文件形式进行重写。
