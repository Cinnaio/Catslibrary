# 书籍可见范围（2026-10-16）

## 规则与操作

后台「小说管理」的新增/编辑弹窗增加「可见范围」：公开、仅管理员、管理员与指定用户。指定用户支持按用户名/昵称搜索、分页、多选和移除，最多 500 人。普通用户获得发现与阅读权限，编辑作品、管理章节和调整授权仍仅限管理员。列表支持按范围筛选，并标记私密作品。

可见范围与内容分级独立。服务端先检查作品可见性，不可见的书籍详情、目录、正文、图片及社区入口沿用不存在资源的响应；再执行原有 restricted 阅读规则。授权普通读者不会绕过限制级要求；有效管理员仍可审核。未知/异常 visibility 不作为公开处理。

迁移 058 为存量书籍设置 public，revision 为 0，保持已有公开行为。抓取/导入等未显式设置范围的新书仍默认公开。编辑 API 未传 visibility 相关字段时保留现有范围，兼容旧客户端。

## 服务端覆盖

- 书库搜索、分页、定位、总数、分类集合、分级统计及 hiddenRestricted 均先过滤不可见作品。
- 小说详情、目录和章节正文；封面及条件缓存；正文插图与段评图片。
- 评论、回复、点赞、举报、评分、段评列表/个人段评及相关写入。
- 收藏、书架、最近阅读、进度与墓碑、书签、历史阅读统计及旧数据恢复/修复预览。
- AI 前情提要、回顾和划选图片结果的读取使用同一可见性条件。
- 初始 HTML（包括未配置 SEO origin 时）、首页静态摘要、网站地图和分享元信息。私密作品不输出 SEO 正文或可索引的作品元信息；授权读者可加载应用，但仍 noindex。

SQL 可见性条件集中在 api/src/services/novel-visibility.ts，并在分页/计数之前执行。身份来自服务端验证的会话；有效 Cookie 与 Bearer 均可用，显式无效 Authorization 不回退到另一个账号的 Cookie。

## 授权变更与缓存

授权通过小说编辑请求与元数据在同一事务提交。锁定作品行、校验 visibilityRevision、验证用户、更新授权和写审计共同成功或回滚；版本冲突返回 409 并保留编辑草稿。审计保存操作人、前后范围/用户集合、版本和时间，仅管理员可读；弹窗展示最近 30 条。

服务端后续请求立即按最新权限判断。撤销授权隐藏收藏、书签、进度与统计，但保留记录；全量书签同步只替换当前可见作品，重新授权后恢复。私密封面使用 private, no-store，条件请求也先检查访问权。

Web 详情/阅读页在重新聚焦、恢复网络和页面重新可见时复查权限，并在可见期间每 60 秒复查。明确的 404/分级拒绝会清掉展示与阅读器内存缓存。书库和书架在同样时机刷新。网络临时失败不推定权限已经撤销。已经交付、下载或复制的内容无法远程收回；这不提供 DRM。

本次实现 Web 管理入口与共享 API，未修改独立 iOS 仓库或提供设备验收。旧客户端读取共享 API 时受服务端可见性约束；新增管理入口和原生缓存/图片认证体验仍需在独立客户端验证。

## 上线与验证边界

API 启动迁移器会应用 058_novel_visibility.sql；上线必须同时更新 Web/API 并正常完成迁移。此次只在隔离测试数据库和本地测试站点验证，以本地提交交付；未迁移当前开发库或线上数据库，未部署或推送。

测试覆盖游客/指定读者/无授权读者/管理员，404 与不存在资源一致、分级独立、Cookie 与错误 Bearer、统计与分类过滤、私密创建、变更事务回滚、版本冲突、撤销及恢复记录、二进制图片和条件请求、初始 HTML/网站地图、个人阅读数据与历史统计。浏览器使用隔离 PGlite 数据和测试账号，验证保存后的授权对象、1440px 桌面、390px 手机及深色主题；弹窗与固定底栏均在视口内，无横向溢出。
