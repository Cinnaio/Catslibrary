# 书内正文搜索

Web 与 iOS 在作品详情及阅读器提供「正文搜索」。关键词为 1–80 个 UTF-16 字符，按字面忽略大小写匹配；不提供正则、通配符、模糊检索或搜索章节标题。仅搜索当前作品已入库正文，未抓取章节不在范围内。

每个结果代表一个匹配章节，展示章节标题、首处命中的纯文本片段和本章命中数量。HTML 正文会去除标记并解码实体，沿用正文广告清理；不返回整章正文。点击结果后，Web 定位并高亮关键词，支持本章上一处／下一处／结束定位；iOS 滚动模式定位命中段落，分页模式定位命中所在页，并高亮关键词。单章最多高亮 1000 处。正文变更后无法定位时显示说明。

## 接口与检索范围

`GET /api/chapters/search?novelId=...&q=...&contentMode=safe|adult&cursor=...`

- 返回 `novelId`、`query`、`items`、本次检查的章节数 `scanned` 及 `nextCursor`。每项包含 `chapterId`、`chapterTitle`、`chapterOrder`、`snippet`、`matchCount`。
- 每次最多检索 200 章、返回 20 个匹配章节，按 `(sort_order,id)` 游标继续；客户端累积展示已找到的结果和已检索数量。存在游标时明确说明后续章节尚待检索，用户点击「继续检索后续章节」推进。部分无命中不等于全书无命中。
- 服务端每批读取 20 章，在服务端提取文本，不将整书正文下载到客户端。首版无持久搜索索引、无数据库迁移；检索过程中不冻结书籍快照，正文或章节顺序发生变化时建议重新搜索。
- 共享章节读取的作品可见性和限制级门禁；安全模式不返回限制级片段，响应为私有不可缓存。搜索单独限流：每账号每分钟 30 次、每 IP 每分钟 60 次。搜索结果不进入 iOS 正文离线缓存。
- iOS 搜索结果跳转时读取 `GET /api/chapters/:id?format=text`，使用与搜索相同的纯文本提取结果以定位 HTML 及实体正文；普通正文接口的原始格式和数据库内容不变。书内搜索需要联网，离线阅读器不显示该入口。

Web 使用共享 SearchField、ReadingDialog、Button、Spinner 和异步／空态组件；列表保留真实请求过渡与入场动效，减少动态时取消动效。旧输入、已关闭搜索、账号及内容模式变更后的响应不会覆盖新视图；后续检索失败保留已有结果和重试，收到禁止访问或不存在响应时清除结果。搜索面板打开期间暂停阅读计时和自动滚动。

## 交付与验证

发布目标为 API/Web `0.7.0` 与 iOS `0.3.0 / build 18`；上一提交 `34dbf01c` 的网站部署及 iOS 构建已成功，本次新增功能按小版本递增，源码变化同时递增原生构建号。用户已授权推送并启动网站部署与未签名 IPA 构建，明确不等待完成；运行结果与设备验收另行记录。API 与两端需要配套更新。旧 API 不支持搜索时展示失败提示，iOS 提示核对 API 版本或作品访问状态。

定向回归：API 7 项覆盖可见性、限制级门禁、HTML／实体和纯文本读取、特殊字符、稳定游标及检索预算；Web 6 项覆盖结果跳转、部分无命中、失败保留、过期响应、账号变化、非破坏高亮及进度恢复后定位。API/Web 类型、Web 组件边界与样式检查、差异检查通过，新增搜索源文件的定向 ESLint 无错误或警告。API 生产构建已通过；未运行完整测试套件、Web 生产构建、浏览器视觉验收或执行本地部署，Web 构建和生产发布交由 Deploy 工作流。Windows 环境没有 Xcode／Swift 编译器，iOS 原生编译、分页与滚动定位、VoiceOver、真机验收及 IPA 构建仍待完成。
