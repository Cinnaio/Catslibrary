# 独立小说分析报告

日期：2026-11-10。API 1.2.0 / Web 1.4.0 未发布候选。

用户最终确定本阶段目标为“先把分析报告做好，供我阅读和核对”。本文件取代此前未实施的 Agent 整合草案；goal 初始文字中的 Agent 整合已被用户明确取消。当前实现仅重构独立小说分析模块，不更改 Agent 工具、会话、记忆或摘要。

## 使用流程

从作品工作区、小说行菜单或创作工作区的“小说分析”进入。选择作品、起止章节、主题及关注问题，显式提交后后台读取全部所选正文，生成中文 Markdown 报告；长范围先分组保存阅读记录。默认选前三章，范围可自行调整。

点击报告中的来源编号查看生成时的正文快照，也可打开当前章节核对。正文、章节顺序或范围变化会提示；历史报告仍保留旧依据。“修订报告”保存人工版本并保留模型原稿；未保存输入按账号、作品和报告暂存在浏览器会话中，切换后可继续，版本冲突先对照最新内容。“按此范围新建报告”仅填写表单，点击生成才创建新报告，旧报告不被覆盖。

离开页面不会停止任务。停止、失败或服务重启后保留已完成阅读记录，显式继续读取尚未完成部分。若正文已改变，需要新建报告。网络不确定时保留原请求标识，重试找回原报告。刷新失败保留已显示内容，并提供手动重新读取。

原续写界面的档案功能改名“续写档案”，仍保留已有数据与生成流程。新报告不写入这些档案，不进入作者约定或续写上下文。

## 实现边界

- 迁移 `082_novel_analysis_reports.sql` 单独存储请求、正文快照、分段记录、整理检查点、模型原稿、人工修订和当前任务。任务中心的记录删除不删除报告；小说删除按外键级联清理报告。
- 使用通用 AI 客户端、供应商快照、用量记账、任务租约及管理员鉴权；没有引用 Agent 服务。借鉴其明确来源、按需回读、操作幂等和显式恢复的设计。
- 正文按最多 12000 UTF-16 字符分段，优先段落边界且不拆代理对；所有所选段落都读取，不截取每章开头。单次最多 200 万原始字符，超出需分批选范围。
- 所选正文不超过 20000 字符时直接生成报告，减少中间归纳及调用。更大范围将相邻来源合成最多 12000 字符、8 段的一组，逐组完成即保存；阅读记录较长时进一步整理，原记录保留。最终模型可调用仅限当前报告的 `read_source`；最多 8 轮，每轮 4 次，原文回读总计最多 48000 字符，重复来源不重复返回全文。给模型的材料只包含来源编号、章节标题、分段及正文，不包含数据库散列、偏移或目录序号。
- 每次模型调用只尝试一次，不自动付费重试。不完整、拒答或空输出不标为完整报告；记录实际收到的用量，包括已取消任务的迟到回复。
- 检查点在事务内检查任务归属与活动状态，旧执行器不能写入恢复后的报告。请求标识按账号唯一，并对标准化请求比对；人工修改使用乐观版本检查。
- 报告以自然语言表述事实、认知、计划和推断。不再以复杂状态账本和强制语义规则拦截整份报告。可定位来源不等于判断正确；没有把测试通过或模型回读次数当作内容验收。

## 检查与内容复核

必要检查共 58 项通过：报告后端与实际路由 9 项、新界面 5 项、受入口更名影响的旧创作面板 44 项。覆盖来源与账号边界、长章完整分段、停止及恢复、迟到写入、幂等提交、原稿保留、编辑冲突、未保存修订和切书隔离。API/Web 类型检查、评阅脚本类型检查、新模块 ESLint、组件边界检查、API/Web 构建通过；082 构建副本与源文件散列一致。既有面板的 React Hooks 警告和 Web 大包提示保留，不混称为错误。没有全量测试、浏览器截图或真实界面验收。

`api/scripts/evaluate-novel-analysis.ts` 默认只打印计划；显式 `--live --output <新的 .tmp 目录>` 才使用已配置模型。默认重放旧 v9 前三章，可用 `--source <冻结 source.json>` 加真实作品；`--chapter-count 3–20` 控制真实样本范围，`--skip-regression` 和 `--skip-baseline` 用于明确省略已有对照。每组至多 9 次请求，分段流程与直接正文基线均留档，不自动复测。旧 v9 材料是已知回归样本，不是未见验收集。真实作品正文与响应只保留在忽略目录。

本轮共 9 次真实模型请求，输入 47,862、输出 20,594 Token，上游报告费用合计 USD 0.013026。初版两个逐章步骤均在 2500 输出 Token 内耗尽思考额度，原失败保留；对应直接正文基线完成。简化后两个短范围报告各一次请求完成。代码助手核对了取消计划、铜牌转手、未完成维修、人物误解、倒叙与当前线、书籍交接及公交方案尚未完成；仍有未知性别被补成代词、部分判断缺引用等问题，不能称为独立人工验收。短报告生成后还精简了模型可见的目录元数据并加入相邻分组合读，没有把旧响应标为这些后续改动的完整复验。

真实作品 16 个来源、22,931 字符的长范围实测，首组 7 个来源的阅读记录已保存；第二组收到上游内容拒答。直接正文基线也收到拒答，整份长报告未完成。此结果验证了失败后记录保留，不证明长范围语义质量。完整元数据见 [诊断记录](diagnostics/novel-analysis-reports-2026-11-10.json)，原始材料位于 `.tmp/novel-analysis-review-2026-11-10*`。

首期不承诺全书语义准确率。较大范围会增加调用成本并经历多层归纳，需要通过实际阅读评估信息损失；本次小范围复核不能替代整本长篇验收。
