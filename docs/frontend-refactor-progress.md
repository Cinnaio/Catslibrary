日期：2026-11-04。Goal：Web 全站视觉与信息架构迁移。分支：`codex/web-design-and-workspace-refactor`，基线 `d2dbb3c5`。

## 硬约束

1. 参考 cats-watching 的实际令牌、外壳与组件，不修改参考项目；重构覆盖公开页面、全部后台子视图、阅读器和浮层。
2. 保留现有业务、API、URL、查询参数、权限、门禁、账户隔离、阅读进度和持久化数据；旧入口可达。
3. 布局由代理先安排：读者围绕查找/收藏/继续阅读，后台围绕作品/创作/任务；低频模型与站点配置进入系统分组。
4. 保留明暗/跟随系统、自定义强调色、阅读字号和宽度。迁移后 portal 与页面使用同源主题。
5. 优先复用现有控件行为和业务组件，局部样式有明确所有者；禁止以全局尾部覆盖层替代完整迁移。
6. 移动导航、触控目标、安全区、焦点与键盘完整。不主动截图，不启动长单元/E2E套件；必要定向检查、Web类型检查及生产构建必须完成并如实记录。
7. 不操作真实业务数据、数据库、凭据、外部发布与部署；不推送或改写历史。版本与日志按实际Web交付更新。
8. 不在仅有方案或局部页面时结束goal；每个模块有迁移、检查和剩余项记录，未验证内容不写成通过。

## 验证记录

源码候选：Web `0.4.0`；工作区基线 `d2dbb3c5`，源码见本条所在的 Web 工作区重构提交。以下检查均为本地结果，未部署。

- 最终 Web `0.4.0` 类型检查通过；Vite 生产构建通过（24.44s）。构建仍提示入口 JS chunk 超过 500kB：556.17kB、gzip 177.31kB；没有因警告跳过构建，也没有借本次视觉迁移更换构建框架。
- 实际浏览器（本机 Edge，无截图）：书库在 1920/1440/960/701/700/390/320px 复查均无页面横向溢出。发现并清除了旧横向卡片规则。顶栏滚动收拢后高度 56px，正文位置变化为 0。
- 明暗主题切换实际生效，侧栏主题菜单完整可见；手机导航 Escape 关闭后焦点返回入口，打开抽屉后切到桌面会自动关闭。
- 30 个后台入口/子视图在 1440/390/320px 的隔离失败响应下均能渲染，无页面脚本异常、无页面横向溢出。筛选轨和分段栏内的横向滚动属于局部容器，不作为页面溢出。
- 使用合成数据检查了收藏、阅读记录、账户资料、作品详情、阅读正文和作品表格，覆盖 1440/700/390/320px，均无页面横向溢出或脚本异常。
- 作品编辑弹窗为 24px 圆角，1440/390/320px 下均在视口内；字段高度分别为桌面 42px、手机 48px。更多操作菜单为 20px 圆角；从作品进入创作，再切换草稿，URL 和请求均保留作品 ID。
- 从后台经站内导航返回书库后，卡片仍为纵向目录布局，页面横向溢出为 0，没有旧后台 CSS 再次覆盖书库卡片。
