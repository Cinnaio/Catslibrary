## 使用与证据导出

```powershell
# 默认只显示计划，不连接数据库或模型
npm run review:agent:local

# 当前已准备环境；同一命令启动API与Web，Ctrl+C停止
npm run review:agent:local -- --serve --directory .tmp/agent-local-review/2026-11-10

# 导出到一个尚不存在的目录
npm run review:agent:local -- --export --directory .tmp/agent-local-review/2026-11-10 --output .tmp/agent-review/human-trial-new
```

新建另一份环境时，显式指定源配置后使用 `--prepare --source <冻结审阅包> --directory <.tmp/agent-local-review下的新目录>`。脚本只接受本机数据库，核对快照散列，拒绝覆盖目录；启动与导出再次核对独立数据库名称和081迁移。失败留下的任务目录／数据库不自动删除。

导出新增来源类型、请求标识、记忆及确认动作状态，关联会话子任务，便于区分“完成／已采纳／已发布”和恢复重复。没有作者消息、或同一会话不足3个非回填摘要时，材料明确标记未覆盖；空会话不再被误判为具备真实修正证据。
