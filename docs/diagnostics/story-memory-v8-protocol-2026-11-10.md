实现与评估工具于 `eefa7178` 冻结，140 项 API 定向回归、API/脚本类型检查和变更文件 ESLint 通过。随后编写 [十章渡口故事](../../api/scripts/fixtures/story-memory-v8-unseen.json)，该故事的模型输出未参与实现调整。本协议和样本在第一次真实调用前提交；v7 的输出仅作为开发诊断，不复用其评估目录和失败预算。

采用空隔离 PGlite 和实际章节提取/独立复核路径。使用配置文本模型，非流式、关闭思考、每次最多 16,000 输出 Token、300 秒；每段正常为抽取和复核各一次请求。冻结运行代码、抽取提示词、复核提示词、配置、样本、提交与供应商指纹，保存每次响应及两种系统提示词哈希，不在评估中修代码。

每章总计最多三次尝试，全样本最多五次失败，跨人工恢复累计最多四十次模型请求；任一上限触达停止。每次失败先人工阅读错误再决定是否显式恢复，不自动重试模型或语义失败。历史补查最多三轮，其请求同样计入总预算；传输开始前预占预算，异常中断不返还。到达预算后不换目录继续同一评估。

逐项人工复核全部预期，按该章结束时有效状态判断，记录符合/部分符合/不符合/未评估。特别核对目标与进度、进度与位置、完成后的持续状态、相近姓名、同类物品、两次转手、认知非对称传播与封箱内容；还要检查复核模型的漏判和误判，不能以复核通过代替内容验收。区分逐章首次尝试与有人工重试后的前缀；后续章节首次结果以已经通过的前缀为条件。
