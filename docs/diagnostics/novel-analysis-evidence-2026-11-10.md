# 小说分析事实与引用核对修复验收

日期：2026-11-10。基线 `2a8e22bc`，分支 `codex/ai-writing-analysis-workspace`。源码来源为本文所在本地提交。方案见[修复方案](../novel-analysis-evidence-plan.md)，机器可读结果见[诊断记录](novel-analysis-evidence-2026-11-10.json)。

## 已实现

- 新报告两条生成出口、人工保存和应用建议后自动核验直接引句；历史报告读取时按需核验。对照冻结原文、章节和连续分段，不将近似、拼接、段末合并引用当成逐字与逐句出处认证。
- “核对主要结论”先显示范围，可手选最多8段；原文上限24000字符，整段超额或没有有效来源则不纳入。一次显式操作最多一次模型调用，沿用当前模型、思考与超时，不自动重试。
- 核对记录独立于分析生成任务，绑定报告修订、有效内容散列、来源指纹和检查器版本。支持幂等找回、停止、失败保留、迟到结果过期，以及原文对照后应用最小修订。
- 代码逐条验证模型给出的原文与修改位置。引号内部替换只在字面证据确定且外侧已有同源标记时移除冗余标记；新建议若制造直接伪引语或错源会被丢弃并标记检查不完整。
- 自动选择避开已有引用或事实疑点的报告；手选附带当前版本的疑点与有界原文。Agent阅读同步返回核对依据；原有任务快照不改写。
- Web增加轻量折叠核对区、实际覆盖与原文按钮、修订前后对照、任务与审计标签。iOS同步任务、审计筛选及网页报告入口，暂不打包。

## 固定真实模型批次

调用前冻结四组错误／正确对照，共8个非私密合成报告，每项一次。原始请求、响应、费用和隔离数据库保存在忽略目录 `.tmp/analysis-evidence-2026-11-10/`，没有把原书正文提交到仓库。使用当前供应商及low思考、300秒分析超时，不更换模型或调整共享配置。以下是本批结果，不是总体准确率。

| 用例 | 预设条件 | 实际结果 |
| --- | --- | --- |
| 担心被看到，却写成父母实际在场 | 找出错误 | 检出；同时引用担心与父母不在现场的原文，建议恢复正确在场范围 |
| 正确区分担心与父母在邻镇 | 不提修订 | 未提修订 |
| 概括被写成直接原句 | 找出错误 | 检出；原始建议含引号内冗余来源标记，最终代码离线归一化后可应用为原句 |
| 准确直接原句 | 不提修订 | 未提修订 |
| 问题错标下一章，回答正确 | 找出错误 | 将问题改标S1，回答保留S2 |
| 问答分别对应两章 | 不提修订 | 未提修订 |
| 额外样本：听说计划写成目睹完成 | 找出错误 | 检出；按后文改变计划恢复仍持有钥匙的事实 |
| 额外对照：听说计划、没有目睹，后文仍持有 | 不提修订 | **未满足预设条件**：模型认为“没有目睹”只标S1不足，建议改为S1明确记载的“当晚没有去仓库”；没有反转持有事实，但仍属于额外建议，不能计为无误报通过 |

8次均运行完成。四个错误样本被检出，三个正确对照不改写；最后一个对照存在引用范围争议，保留原预期和结果，未重跑挑选。模型建议仍须由作者确认，不作为自动全书认证。

在隔离库实际走通了“在场误判→核对建议→作者应用接口→新修订→续写参考与Agent读取”链路：模型原稿保留、修订号增加、两条下游读取均使用新内容。此处验证的是输入数据流，没有额外发起真实续写生成，不能据此保证今后每次模型创作都遵守事实。

总输入3656、输出4070 Token；7次已知费用合计USD 0.001442，1次费用未回传，不按0费用解释。原始模型输出与最终确定性解析分别保存；解析修复后的8个响应离线回放没有新增模型调用。

## 原书旧样本离线复查

此前选定的12处非露骨引句只做离线处理：Q02定位为未找到连续原句，Q05定位为来源错位并给出S92候选。其余11处原句仍能在此前人工确认的来源连续匹配；其中段末合并标源或引号用途不确定的内容仍标待核对，未伪装成逐句认证。Q05本身属于这11处原句之一，错误在引用位置。

这些是已知定向样本，非随机、非盲测；没有独立通读99章，也没有再次生成长篇报告。此结果证明已知引用问题能被定位，不证明所有事实误判都能发现。
