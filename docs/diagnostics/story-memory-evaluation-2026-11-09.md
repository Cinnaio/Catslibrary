## 后续优先级

1. **统一认知与客观事实契约。** 提示词要求知道／不知道都使用 belief，但现有兼容路径允许 belief 转 fact；这次第 4 章即失去 perspective。应将客观发现与各人物知道的内容分开表达，验证认知归属而不只验证该字段存在。
2. **明确线索解决的合法变化。** 当前校验要求沿用 certainty、主体和主题，模型却多次输出 clue → fact，并通过删掉 replaces 回避单条报错。应给出完整的“解决旧线索、另存客观事实”的结构与错误反馈，保留主题所指的具体事项，避免一场谈话覆盖另一场谈话。
3. **处理重复状态与混合主题。** 第 7 章仍有 3 条银剑归属、2 条铜钥匙归属、2 条合作关系和2条红线状态。还存在把修船进度写入位置摘要的问题。需要稳定的主题和核心主体约定，不能简单按同名 label 自动去重或覆盖。
4. **修正后使用独立样本复评。** 先验证第 8–10 章及以上失败案例，再增加不同名字、措辞、长章、多人视角与主动历史补查。当前 1,350 字符合成样本不能证明真实长篇质量、吞吐或成本。
