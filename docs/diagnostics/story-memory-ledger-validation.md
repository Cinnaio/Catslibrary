## 实现边界

- 一章的完整变化通过校验后才持久化；正常新增章节不再重写全书档案，关系、情节与自动星图复用这些变化。
- 旧事实保留，状态变化引用可核对的前置记录。历史起点不使用未来记录；旧章修改会使依赖的后续记录失效。
- 长期状态与普通章节事件分别保存。普通事件和已解决事项不默认进入后续章节工作集；物品转手、人物移动和认知纠正保留更新后的持续状态及可追溯旧记录。
- 模型默认获取相关当前状态，必要时补查历史。没有固定记忆输入 Token 上限，相关事实较多时仍可能需要更长上下文。
- 检索为实体/别名、主题及字面关联，尚无向量检索；语义相近但措辞不同、跨实体隐含联系可能漏召回，需要真实小说评估。
- 人物认知、全局约束和心理边界采取保守保留策略。大量相关约束仍会增加输入，不能保证任意复杂章节都有恒定成本。
- 当前试验会读取并校验章节依赖前缀，在内存中筛选记录；保存和档案展示仍随总记录量增长。此次减少的是重复模型分析与无关输入，不是证明数据库读取、页面渲染或任意长篇都能保持恒定延迟。
- 发布后台准备默认关闭；启用会实际计费。运行中的目标不被追加章节悄悄改变，新目标持久排队；暂停、失败和服务重启后支持手动继续。
- 爬虫/书源同步暂不自动调用发布准备入口。原模式、人工档案和旧图谱的显式生成仍保留。

## 真实模型对照


## 试用与回退

先部署代码并应用 069 迁移，在“参数调优 → AI 创作”选择“章节增量记忆（试验）”。选一部小说，点击任一情节/关系更新入口，完成首次记录建立。核对档案中的正文依据、人物认知、状态变化与未解线索，再预览续写材料；建议先保持发布后后台准备关闭，确认表现后再启用。

切回“完整档案（原模式）”即可让后续更新沿用原算法。建议先暂停并等待当前分析退出，再切换。切换不会删除已发布正文、长期章节记录、现有人工校正或保留的档案历史；不会自动恢复某份旧档案正文，旧版本仍可在既有历史入口查看。
