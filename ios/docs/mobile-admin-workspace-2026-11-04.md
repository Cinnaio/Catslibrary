# iOS 作品工作台与创作流程

日期：2026-11-04。此记录描述本轮源码修改与验证范围，不代表已经构建 IPA、推送或部署。

## 管理入口

- 仅管理员可在书籍详情的工具栏、在线阅读器的更多菜单进入「管理这本书」；小说管理的操作菜单和长按菜单也提供同一入口。
- 作品工作台携带固定作品上下文，串联资料编辑、章节管理、追更、目录更新、创作、封面、生成内容和近期任务。
- 从阅读器进入时，携带当前章节作为续写起点，并按该起点重新读取画像状态。初始作品即使不在前 200 本选书索引中，也能直接进入创作或封面页。
- 从工作台进入创作、封面时固定该作品；旧任务恢复不会把当前页面切换到其他作品。另一作品的运行中创作任务仍可以查看和处理。

## 管理首页与任务

- 首页展示近期运行任务、失败/中断任务、待处理创作草稿、本机未提交输入、最近管理作品和常用操作。
- 原有全部模块仍保留，可通过「全部管理功能」或首页搜索进入。
- 任务中心汇总最近 100 项 AI 任务与服务端近期抓取任务，可按进行中、失败与中断、全部筛选，也可从作品工作台只看该作品。
- 单个 AI 任务直接查询任务详情，避免依赖全局列表前 200 条；续写、新写章节、大纲任务可直接打开该任务的精确结果，复用既有编辑与发布界面。任务重试后切换到新任务。
- 抓取任务进入原任务操作界面并定位该任务；该界面在定位模式中关闭全局清理入口，保留既有终止和重试行为。
- 新增汇总请求绑定启动时的账号 token，过期响应与取消任务不回写；前台任务页定期刷新，书目和草稿摘要每分钟最多自动刷新一次，手动刷新可以立即更新。
- 最近管理作品按账号保存在本机，去重并最多保留 8 本；进入时重新读取服务端作品，已删除或无权访问的作品不会直接使用旧快照进入管理。

## 创作输入与发布

- 创作页分为「作品 → 要求 → 检查并生成」；高级内容偏好、画像与续写辅助按需展开。创作要求可以展开为大编辑器。
- 未提交输入按账号与工作台作品分开保存，包括标题、要求、大纲、背景、章节起点、详细约束、字数、章数及当前步骤。首页提供最近 5 个输入草稿的继续入口。
- 通用创作与各作品工作台的输入单独保存；恢复输入不会自动提交生成任务。清空输入会移除对应本机草稿，成功提交任务后移除已提交的输入快照，其余账号、作品的草稿保留。
- 服务端生成草稿继续复用既有修改、冲突检查、发布确认和批量发布流程，不把本机输入草稿当作已生成章节。
- 「本书草稿与发布记录」由服务端按 `novelId` 过滤后计数、分页和分组，重名作品也按 ID 区分。
- 修正 iOS 的「全部状态」请求：显式发送 `status=all`，防止服务端按缺省值只返回已发布内容。

## 跨端与部署

- `/api/ai/generations` 新增可选 `novelId` 查询参数，并在响应中回传实际作品筛选条件。未传参的调用保持原有范围。
- iOS 的本书列表要求服务端确认筛选条件，旧服务端忽略该参数时显示升级提示，避免把全站草稿显示为本书草稿。应先部署对应 API，再使用新客户端的本书草稿入口。
- 无数据库迁移，不改发布工作流。现有网页后台、权限及危险操作确认机制继续复用。

## 验证

- API 的 AI 路由 97 项测试与生成内容服务 8 项测试通过，共 105 项；包含作品 ID 筛选、同名作品、跨作品同名批次、分页计数、分组以及已有生成、发布、权限与任务行为。
- API TypeScript 类型检查、改动 TypeScript 文件 ESLint/Prettier 检查通过。
- 新增 6 项 Core 行为测试，覆盖账号/作品隔离、重启恢复、多行内容与章节锚点、单草稿删除、近期作品上限与去重、缺失账号不写入。
- 新增 4 项原生 UI 用例，覆盖索引之外作品的输入恢复与跨账号隔离、当前章节传递、精确任务结果、普通读者无管理入口；更新已有模块导航测试适配工作台入口。
- Windows 本机未安装 Swift/Xcode：Core 与 UI 用例尚未原生执行。现有 PowerShell smoke 和 Swift 语法解析不能证明 Swift 类型检查、Release 构建或设备交互成功。仍需 macOS 构建及 iPhone/iPad 的键盘、大字体、返回导航、账号失效与弱网验收。

本轮集中改善作品、任务、创作到发布的流程。完整 iPad 管理分栏布局与高级配置表单的进一步改版另行验收。
