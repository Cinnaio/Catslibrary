# 缓存预算、离线下载与书架目录改善

日期：2026-11-04。本文记录源码行为；不代表已部署 API、构建 IPA 或完成真机验收。

## 用户可调缓存

- 入口：我的 → 存储管理 → 自动缓存上限。默认 256 MB，提供常用档位，也可输入 32–8192 MB 的整数。
- 设置按设备保存在 UserDefaults，不跟随账号同步。自动图片磁盘缓存分配 3/4，章节磁盘缓存分配 1/4；内存缓存仍由原有上限与系统管理。
- 显示自动缓存占用、章节缓存、图片缓存和离线章节文件占用。该上限不包含字体、主动下载、数据库、偏好设置及系统目录开销，因此不是整个 App 的总存储上限。
- 降低上限时淘汰较旧的自动章节缓存，并更新图片 URLCache 的容量。重新启动后继续使用已保存的预算。

## 离线下载

- 主动下载移到 Application Support 下独立的 `ZhiZhouOfflineChaptersV1`，按账号分区，并排除 iCloud 备份；自动章节缓存仍在 Caches 下。
- 清理自动缓存或减小预算会保留离线下载。下载只在持久文件成功写入后登记，写入失败会显示错误。
- 升级时将现有按账号离线目录对应的缓存搬入持久目录；调整预算或清理缓存前迁移所有账号的旧下载。迁移写入失败时中止清理/预算调整，保留旧副本。旧版本已被淘汰的文件无法恢复，需重新下载。
- 批量下载显示处理数、保存数和失败数，并可在作品的「离线下载」面板重试失败章节。失败重试列表仅保留当前会话；已成功下载的文件与目录会持久保存。
- 离线阅读入口直接读取本地章节，不再先等待网络请求超时。在线重新拉到修订正文后，会更新该章节已有的离线副本。

## 书架与目录

- 书架按 50 本分页，使用服务端总数，支持失败重试及防止旧请求覆盖新查询。
- 新增书名/作者搜索，收藏时间、最近阅读、最近更新、书名排序，以及未开始/已开始筛选。查询在服务端过滤后计数与分页，仍应用账号与内容可见性约束。
- 详情页使用 `novelId` 查询收藏状态，避免前 50 本之外的作品被误判为未收藏。阅读进度与目录并行加载，进度读取完成前暂不开放可能指向第一章的续读按钮。
- 详情目录与阅读器目录支持搜索、正倒序；阅读器目录支持输入有效章号直接打开章节。下载选择模式展示完整目录，避免筛选隐藏的章节被拖选。
- 目录内存缓存有效期为 60 秒，正文为 300 秒。详情与目录下拉刷新跳过内存缓存；阅读器发现目录缺少目标章节时也强制重新拉取。目录打开时先展示已有章节，再按有效期检查更新。
- 书架的搜索、排序和阅读状态筛选需要部署本次 API；分页与单本收藏查询复用原有接口。没有增加数据库迁移。
