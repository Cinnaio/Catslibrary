# iOS 原生对话创作

2026-11-09，基于主仓库 `e7625672` 的接入源码；候选版本为 `ios/project.yml` 的 `1.2.0 / build 24`。使用主仓库 `ios/` 工程，不是旧的独立 iOS 仓库。初次接入仅完成本机源码检查；现已获授权提交、推送，并运行 iOS 构建和网站部署，实际结果统一记录在 [发布记录](../../docs/releasing.md)。

## 入口与操作

- 管理员登录后，首页底部「创作」进入对话工作区；管理后台 AI 服务也有入口。
- 从「管理这本书 → 对话创作」进入时带入作品与当前章节；新建对话可选择续写起点，空起点遵循服务端规则使用最新正式章节，无章节时从头创作。
- 小说选择分页读完整索引，支持搜索；会话按小说分页，聊天可以读取更早消息。旧事件的产物／采纳记录通过 ID 单独取回。
- 聊天输入与正文分别占位，默认一行、最多六行后内部滚动。文本模型菜单使用现有预设，单轮发送冻结模型；封面继续使用服务器图像配置。
- 助手回复显示标题、强调、链接、列表、任务清单、引用、围栏代码和表格。代码、用户消息、错误和草稿按原文显示；无 WebView、原始 HTML 执行或远程 Markdown 图片抓取，链接只允许 HTTP(S)／mailto。
- 「产出与采纳」展示真实任务状态、未完成预览、草稿全文、改写前后和鉴权封面。可停止各子任务；「停止回复」只停止协调任务。完成的分析可进入原 AI 任务页查看。
- 发布章节、替换草稿、采用封面和恢复上一版，先生成服务端保存的预览，再在 sheet 中明确确认；确认仅传操作 ID。失败／冲突保留当前内容，重新预览；执行占用释放且服务端允许恢复后，才提供继续执行。
- 会话设置保持原有内容偏好语义，成人模式派生成年人确认，关闭时归一化；保存使用打开编辑时的 `expectedUpdatedAt`，冲突不静默覆盖，读取最新设置需用户主动选择。

## 恢复与隔离

对话模型固定账号 token、会话 ID 和站点。请求前后与流式逐包核对身份；退出／换账号由原根视图重建并关闭页面。切后台或离开暂停订阅，服务器任务继续运行；返回后重新读取原会话和任务，流中断以 GET 核对并退避重连，不重新 POST 生成。

同任务、同轮的较旧数据库检查点不能截短已收到的预览；已保存的助手消息会抑制该轮重复预览。会话刷新合并事件 ID，更早历史的游标独立保留；长时间离线超出最近消息窗口时重新建立历史游标，避免永久跳过中间消息。任务完成后刷新产物；超过最近产物窗口的旧记录可单独刷新。

消息输入保存在独立 `zhizhou.agentDraft.v1` 命名空间，按站点、账号、会话隔离，不混入原写作工作台草稿。发送前保存固定请求 ID、文本及模型；确认接收后只清除该待发送项，保留用户新输入。断线或重启后显示「重试原消息」，仅用户点击才重发同一请求，服务端负责幂等去重。取回文字会明确提示服务器可能已接收，重新发送可能开启新一轮。

## 依赖与验证

需要配套 API `1.1.0` 的对话路由、模型预设、文本任务事件流及迁移 `078_ai_agent.sql`。本次不修改这些后端接口、不执行迁移，也不假定线上已经具备接口；旧服务端的读取失败会在客户端呈现并允许重试。

新增 Core XCTest 共 9 项，覆盖服务端数据形状、同轮检查点防回退、回复轮次去重、进度边界、待发送请求与站点／账号／会话隔离、内容偏好、恢复许可及常用 Markdown／未闭合代码块。Windows 完成 Swift 语法解析及差异检查；没有 Swift/Xcode，**这些 XCTest 尚未运行，语法解析不等于 Swift 类型检查或原生编译**。

后续 macOS 上运行 `swift test --package-path ios/ZhiZhouCore --filter AIAgentTests`，再执行原 `build-ios.yml` 的 Release 构建。按实际提交 SHA 检查构建结果并保存 `build-run.json` 与 IPA 摘要；未经授权不触发推送或云构建。

设备验收只需覆盖关键链路：管理员／普通账号导航差异、从当前章节创建及继续会话、手机键盘与辅助功能字号、Markdown 长表格、上翻时不被流式输出拉走、切后台后恢复、响应丢失后的手动去重重试、模型预设、草稿／封面预览确认及版本冲突。真实模型调用与这些交互本次未执行；旧 IPA 不能用于验收新源码。
